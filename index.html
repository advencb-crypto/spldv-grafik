KETERAMPILAN DASAR WAJIB

📐 Teknik Cepat Menggambar Garis: "Metode Tutup Jari (Tipot X & Tipot Y)"

Untuk menggambar sebuah garis lurus, kita cukup mencari 2 titik saja! Cara termudah bagi siswa SMP adalah mencari Titik Potong Sumbu X dan Titik Potong Sumbu Y.

1. TUTUP x = 0 → CARI y

Titik Potong Sumbu Y

Contoh pada garis 2x + 3y = 12:

Jika x = 0 → 2(0) + 3y = 12

3y = 12 → y = 4

Titik Pertama: (0, 4)

2. TUTUP y = 0 → CARI x

Titik Potong Sumbu X

Masih pada garis 2x + 3y = 12:

Jika y = 0 → 2x + 3(0) = 12

2x = 12 → x = 6

Titik Kedua: (6, 0)

Tabel Pasangan Berurutan: 2x + 3y = 12

x y Titik (x, y)
0 4 (0, 4) ← di Sumbu Y
6 0 (6, 0) ← di Sumbu X

💡 Catatan Guru: Jika konstanta c = 0 (garis melewati titik asal (0,0) seperti y = 3x), pilih nilai x bebas (misal x = 1 dan x = 2) untuk mendapat titik kedua!

ANALISIS KRITIS SISWA

🕵️ Detektif Kesalahan Grafik: Mengapa Titik Potongnya Meleset?

Banyak siswa sudah benar menghitung tabel titik, tetapi gambarnya salah di buku berpetak. Klik kasus di bawah untuk membedah penyebabnya!

Kasus Dimas: Tertukar Sumbu (x, y) Menjadi (y, x) Jebakan Grafik #1

Untuk persamaan 2x + y = 6, Dimas sudah benar menghitung titik potong sumbu: (0, 6) dan (3, 0).

🔍 Analisis Kesalahan: Koordinat selalu ditulis berurutan (x, y). Angka pertama (x) adalah langkah mendatar (kiri/kanan), sedangkan angka kedua (y) adalah langkah tegak (atas/bawah).

✅ Ingat Jembatan Keledai: "Jalan dulu di lantai datar (x), baru naik tangga (y)!" Jadi (3, 0) berada di sumbu mendatar X angka 3.

Kasus Tari: Jarak Skala Antar Kotak Tidak Konsisten Jebakan Grafik #2

Pada sumbu X, Tari menulis angka 0, 1, 2, 3, 4 berjarak 1 kotak. Namun pada sumbu Y, karena angkanya besar, ia menulis 0, 2, 5, 6, 10 berjarak masing-masing 1 kotak!

🔍 Analisis Kesalahan: Selisih nilai antar 1 kotak pada satu sumbu harus tetap/konsisten (misal kelipatan 1 semua: 1, 2, 3, 4 atau kelipatan 2 semua: 2, 4, 6, 8). Tidak boleh melompat dari 2 ke 5 lalu ke 6!

✅ Tips Akurasi: Gunakan buku berpetak dan penggaris agar kemiringan garis tetap lurus sempurna dan titik potong terbaca tepat.
